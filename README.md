NEO Website
===========

Öffne index.html im Browser, um die Website lokal zu testen.

Hinweis: Das Bewerbungsformular überträgt keine Daten automatisch. Es erstellt einen Text, den Bewerber kopieren und über ein Discord-Ticket senden können. Für automatisches Versenden wäre ein sicherer Backend-Dienst erforderlich; Discord-Webhooks dürfen nicht in öffentliches JavaScript eingebaut werden.
